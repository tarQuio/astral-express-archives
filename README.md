# 🚂 Astral Express Archives

**Astral Express Archives** is a comprehensive companion web application for _Honkai: Star Rail_ players. It features an interactive Tier List, a robust Team Builder, and detailed databases for Characters, Light Cones, and Relics.

Designed with a premium, game-accurate aesthetic to provide an immersive experience for Trailblazers.

## ✨ Features

### 📊 Interactive Tier List

- **Rankings**: Up-to-date tier rankings for all characters.
- **Filtering**: Filter by Path, Element, and Rarity.
- **Visuals**: High-quality character cards with "glass shine" effects.

### 🛠️ Team Builder

- **Squad Planning**: Build your dream team with a drag-and-drop interface.
- **Synergy Analysis**: Get insights into your team's elemental coverage and path distribution.
- **Save & Load**: Save your favorite team compositions for later use.

### 📚 Databases

- **Characters**: Detailed stats, skills, and eidolons.
- **Light Cones**: Complete library of Light Cones with stats and effects.
- **Relics**: Browse all Relic sets and Planar Ornaments.

### 🔧 Admin Panel

- **Manage Data**: Easy-to-use interface for updating tier rankings and character data.
- **Mode Specifics**: Manage rankings for Memory of Chaos, Pure Fiction, and Apocalyptic Shadow independently.

## 🚀 Tech Stack

- **Frontend**: [React](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: CSS Modules / Vanilla CSS with modern glassmorphism design.
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router](https://reactrouter.com/)

## 📦 Installation

1.  **Clone the repository**

    ```bash
    git clone https://github.com/your-username/astral-express-archives.git
    cd astral-express-archives
    ```

2.  **Install dependencies**

    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```
