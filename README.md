# 🚂 Astral Express Archives

**Astral Express Archives** adalah aplikasi web pendamping komprehensif untuk pemain _Honkai: Star Rail_. Aplikasi ini memiliki fitur Tier List interaktif, Team Builder yang canggih, serta basis data lengkap untuk Karakter, Light Cone, dan Relic.

Dirancang dengan estetika premium yang akurat dengan game untuk memberikan pengalaman yang imersif bagi para Trailblazer.

> [!IMPORTANT] > **Status Proyek**: Website ini masih dalam tahap pengembangan aktif (_Work in Progress_). Beberapa fitur mungkin belum sempurna dan masih banyak peningkatan yang direncanakan. Masukan Anda sangat berharga!

## ✨ Fitur

### 📊 Tier List Interaktif

- **Peringkat**: Peringkat tier terbaru untuk semua karakter.
- **Filter**: Filter berdasarkan Path, Elemen, dan Kelangkaan (Rarity).
- **Visual**: Kartu karakter berkualitas tinggi dengan efek "kilau kaca" (glass shine).

### 🛠️ Team Builder

- **Perencanaan Skuad**: Bangun tim impian Anda dengan antarmuka drag-and-drop.
- **Analisis Sinergi**: Dapatkan wawasan tentang cakupan elemen dan distribusi path tim Anda.
- **Simpan & Muat**: Simpan komposisi tim favorit Anda untuk digunakan nanti.

### 📚 Basis Data

- **Karakter**: Statistik detail, skill, dan eidolon.
- **Light Cone**: Pustaka lengkap Light Cone dengan statistik dan efeknya.
- **Relic**: Jelajahi semua set Relic dan Planar Ornament.

### 🔧 Panel Admin

- **Kelola Data**: Antarmuka yang mudah digunakan untuk memperbarui peringkat tier dan data karakter.
- **Mode Spesifik**: Kelola peringkat untuk Memory of Chaos, Pure Fiction, dan Apocalyptic Shadow secara independen.

## 🚀 Teknologi yang Digunakan

- **Frontend**: [React](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: CSS Modules / Vanilla CSS dengan desain glassmorphism modern.
- **Ikon**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router](https://reactrouter.com/)

## 📦 Instalasi

1.  **Clone repository ini**

    ```bash
    git clone https://github.com/username-anda/astral-express-archives.git
    cd astral-express-archives
    ```

2.  **Install dependencies**

    ```bash
    npm install
    ```

3.  **Jalankan server development**
    ```bash
    npm run dev
    ```
